# Magnum Economicus: Computation Munster

Michael Emanuel Glover, developed with Codex. Independent economic research white paper. Measured World Bank data and explicitly uncalibrated simulation; no causal national-policy or investment claim.

Read WHITE-PAPER.pdf or WHITE-PAPER.txt. Run `python3 experiment.py`, then `python3 write.py` to regenerate from frozen data. Python dependencies: NumPy, pandas, Matplotlib. LaTeX requirements are listed in typeset.py. World Development Indicators are attributed to the World Bank; source URLs, release metadata and file hashes appear in results.json. The data website identifies the applicable license; use those terms for subsequent redistribution.
