# Rage-comic artwork

The authentic reaction sprite sheet comes from conzett/RageFacesForChat, which credits Reddit’s ffffffffuuuuuuuuuuuu collection. Repository: https://github.com/conzett/RageFacesForChat . The upstream GNU GPL v3 license notice is preserved in UPSTREAM-LICENSE.txt. No extension code is bundled. SVG view boxes select the existing faces without altering the source image.

Higher-resolution Rage Guy: https://freesvg.org/rage-guy (OpenClipart, listed as Public Domain/CC0). Source PNG: https://freesvg.org/img/1307183544.png .

Existing figure captions and event mappings are preserved. The table-flip face retains the original custom vector artwork. Layout uses white panels, black gutters, handwritten-style type, and a two-column reading order. Low-resolution source faces remain raster artwork and may appear pixelated at large sizes.
