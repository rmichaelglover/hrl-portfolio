What changed?

The original search scores a dimensionless algebraic residual and narrows around one grid candidate at each stage. That can reward a larger ellipse through clutter. The new method samples ellipse hypotheses with RANSAC, scores an approximate geometric residual, then refines the consensus locally. Refinement is accepted only when exact geometric truncated-square error improves.

RANSAC supplies the main improvement. This experiment does not demonstrate a Cantor-specific or HRL-specific advantage. The original algorithm is a shrinking grid search, with no relaxation-labeling update.

Where it breaks

A fixed 2.4-unit threshold assumes the original noise scale. Dense clutter can support a wrong ellipse, and a limited random search can miss a good hypothesis. The benchmark uses one complete ellipse and uniform scatter—not organic structure, partial arcs, or real camera images.

Boundary RMSE measures distance from the true noiseless boundary to the fitted ellipse. Precision and recall use exact distances with a 2.4-unit cutoff. Ground truth is used for evaluation only. The report includes bounds, calibration assumptions, and all method summaries.
