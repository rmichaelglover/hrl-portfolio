The dictionary that can read itself.

I am building an English lexicon that includes the letters, their spoken names, punctuation, words, definitions, and the interpreter that reads those definitions. A letter can name itself through a word whose spelling is made from letters already in the same dictionary.

The seed

Every mark gets an entry.

Take N: EN. The left-hand N is a Unicode character and a letter in the alphabet. The right-hand EN is its spoken letter-name and is itself spelled from E and N. The colon is a character, punctuation mark, spoken name, and definition operator—all in the same lexicon.

NUnicode grapheme U+004E
→
ENletter-name · /ɛn/
→
E + Nspelling of “EN”
→
EE + ENletter-names of its letters
The graph may contain cycles. A cycle is recorded as a relation and interpreted to a fixed point; it does not trigger endless recursive expansion.

Alphabet kernel

      
Letter identity, name, and sound are separate but connected.

      
The same graph stores the written character, conventional name, pronunciation, regional variants, and spelling of each name. Click-free text parsing can still expose every layer; audio is an additional grounding channel.

      

      
Letter names and pronunciation vary by dialect. The initial interface uses a US-oriented seed, with explicit variants such as ZEE/ZED and AITCH/HAITCH added as parallel entries.

    


    

      
Formal model

      
One graph, recursively interpreted.

      
Nodes represent Unicode characters, graphemes, letter-names, morphemes, words, senses, definitions, examples, and grammatical constructions. Edges encode names, spells, pronounces, defines, uses, and exemplifies.

      
Dk+1 = Dk ∪ { e : parseDk(definition(e)) succeeds }

Closure: Dk+1 = Dk
Interpretation: relaxed, typed paths through the closed graph

    


    

      
Recursive relaxation

      
Ambiguity stays visible while context does its work.

      
The existing GRRLE text frontend already proposes competing word spans, parts of speech, and phrase hypotheses. The self-interpreting lexicon adds grapheme/name/sound and definition/sense layers to that same field.

      
sᵢ(t+1) = σ(logit(pᵢ) + η Σⱼ wᵢⱼ sⱼ(t))

positive w reinforces compatible readings
negative w suppresses competitors
cycles settle as recurrent support

Scaling path

      
From the alphabet kernel to the full lexicon.

      
The full dictionary is a typed lexical graph with corpus provenance. WordNet supplies senses and gloss relations; pronunciation lexicons supply sound; public-domain text supplies usage and construction evidence. Every imported record is normalized into the same graph, with source and license retained.

      
Coverage grows by closure: the interpreter parses dictionary entries with the same grammar it uses on ordinary English. Unresolved senses remain explicit candidates until usage, syntax, pronunciation, or human correction supplies support.
