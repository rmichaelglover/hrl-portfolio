# We’re All Just People: An Attack on Carriedom

A separate nonfiction moral essay in *Attack on Christendom*, addressed to people tempted by mass violence, extremist recruitment, or revenge against bullies. It is distinct from the Carrie–Emaline literary essay and standalone fanfiction.

Edit `essay.md`, then run `python3 attack-on-christendom/carriedom/build.py` from the repository root. Requires Python `markdown`. The static reading edition uses the journal and neighboring reading-room styles.
