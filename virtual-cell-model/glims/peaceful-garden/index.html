Anticipation without adversaries

“What would you like to do?”

Each resident has a destination and a preference for enjoying roses. The planner computes their preferred next steps, considers up to 3,125 joint actions, and chooses a compatible combination. Other residents’ positions also inform routes around people who might prefer to stay.

Dashed lines show preferred steps for the selected turn. Solid lines show the moves actually agreed upon. Waiting and taking a different path are available actions.

Clearance checks cover the complete simultaneous movement: no shared destinations, head-on swaps, crossing paths, or stepping through the frog’s predicted hop. Hedge cells remain impassable.

Chess games inform the model

From moves to consideration.

Reading source game…

The fraction of non-capturing moves sets the progress weight. The fraction of legal replies landing on the preceding mover’s attacked squares sets the anticipation weight. These are explicit design mappings from recorded board geometry, not inferred personalities.

Michael’s peaceful-world preferences—protect frogs, respect personal space, enjoy roses—are specified separately. Alex retains his preference for prosthetic support. Three archived games seed this first demonstration; the importer can aggregate additional PGNs.

Run the Virtual Person and ROS2 garden

The C++ lesson extends Alex’s original Person class with preferences and checks a proposed move against another person’s anticipated move and a frog’s motion.

C++ Virtual Person · Generated chess weights · Joint planner and PGN importer · Replay generator · Behavior tests

g++ -std=c++17 virtual_person.cpp -o virtual_person
./virtual_person

# In the local cypher_robot_mind ROS2 package:
colcon build --packages-select cypher_robot_mind
source install/setup.bash
ros2 run cypher_robot_mind peaceful_garden
ros2 topic echo /peaceful_garden/state

The separate garden node publishes simulated decisions and offers pause/reset services. It does not issue movement commands to the existing robot.

Originating concept, characters, joint-preference framework and peaceful chess analogy: Michael Emanuel Glover.
Assistant contribution: implementation, interface and verification. This finite scenario tests coordination; it does not establish collision avoidance under unknown real-world motion or optimal planning for arbitrary worlds.
