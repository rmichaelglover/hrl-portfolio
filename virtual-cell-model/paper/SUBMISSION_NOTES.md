## Upload source

Use `virtual-cell-arxiv-source.tar.gz`. It includes `main.tex`, three generated
LaTeX table fragments in `source/`, and all twelve used PDF figures in `figures/`.
There is no proprietary journal template, shell escape, remote resource,
JavaScript, auxiliary build file, unused figure or compiled manuscript in this
source archive. Select pdfLaTeX when prompted. The references are embedded in
`main.tex`. The separate reproducibility ZIP contains code and data.

The clean source is tested by extracting into a new directory and compiling it.
The author still needs to review the actual arXiv-compiled PDF, confirm metadata
and select a license in the submission system. Creating the archive does not
submit or endorse the paper.

Official arXiv instructions consulted:
https://info.arxiv.org/help/submit_tex.html

Those instructions request TeX sources and used figures, advise including any
needed bibliography files, and recommend excluding extraneous build artifacts.
The manuscript uses a fixed date so recompilation does not silently change it.

## Before scientific submission

Read and approve the claims, authorship, acknowledgements and competing-interest
statement. The paper identifies the author as the software's developer and
maintainer; it does not invent funding or institutional affiliations. Numerical
results concern controlled software experiments. No clinical, neural-training,
quantum-decision, or theological empirical result is asserted.
