An evening takes shape.

    What is this little world modeling?

    This browser scene brings Michael Emanuel Glover’s virtual Person framework into an interactive illustration. It uses modeled geometry and two eye origins 64 mm apart for visibility, collision-aware movement, short-lived visual observations, remembered objects, several competing goals, independent family replies, and separate practice states.

    The room and all meters are simulated. This is not live ROS telemetry or a retinal object-recognition system. The C++ Eyes, physiological models, HRL/GRRLE experiments, and real local sleep-study pipeline have their own executable implementations.
