Maestro for Linux

Your own colorful, musical chess room: the full playable board, the Audacity kit, Lecture One, and local player profiles.

Download & install

Debian / Ubuntu · DEBFedora / RHEL family · RPMSource archive

Requires Linux, Python 3.10 or newer, xdg-utils, and a browser. Audacity is optional for editing the music.

Debian / Ubuntu

sudo apt install ./maestro-chess_0.1.1-1_all.deb

Fedora / RHEL family

sudo dnf install ./maestro-chess-0.1.1-1.noarch.rpm

Launch Maestro Chess from your applications menu, or run maestro-chess. The launcher opens a local browser app. To print its address without opening a browser, run maestro-chess --no-browser.

Closing the tab leaves the local process running. Local profiles stay on your computer and are not published to the online community. Your data lives in ~/.local/share/maestro-chess/accounts.sqlite3.

Included

  • Full Maestro: play both sides, select games and pieces, use musical playback, load PGN, and export.
  • Van’t Kruijsing: the 85 BPM reference mix, five lossless audio tracks, and an Audacity import kit.
  • Lecture One: “Memorization is key. Compression is more key.”
  • Local username/password accounts and editable profiles.

The broader project library is available on the website. Installing the package does not install Audacity or publish a profile.
