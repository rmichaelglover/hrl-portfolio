HRL & Maestro for Ubuntu

Install the reusable HRL engine, the classic relaxation-labeling core, or the colorful Maestro Chess desktop app. Tested on Ubuntu 22.04 with Python 3.10 and distribution NumPy 1.21.5.

HRL Python engine

Recommended for the current reusable engine. Persistent priors, a noise label, point correspondence, tracking, consensus, and other experimental modules. Runs locally with NumPy. Includes hrl-demo and the hrl Python API.

Ubuntu · HRL DEBHRL source & builder
sudo apt install ./python3-hrl_0.1.0-1_all.deb
hrl-demo
/usr/bin/python3 -c 'from hrl import RelaxationLabeler; print(RelaxationLabeler)'

81 engine tests passed. The package includes 71 relevant module tests. Optional NLI/LLM integrations need separate dependencies and model/service access. The recursive GRRLE research engine is not part of this package. HRL keeps its existing MIRL-1.0 source-available license.

Classic relaxation-labeling core

The smaller AGPL-3.0 core: pairwise and order-three compatibility tensors, a Python API, and a clustered-object demonstration. This is a separate implementation from the HRL package above; both can be installed together.

Ubuntu · Classic RL DEBClassic RL source & builder
sudo apt install ./python3-relaxation-labeling_0.1.0-1_all.deb
relaxation-labeling-demo
/usr/bin/python3 -c 'from relax import RelaxationLabeling; print(RelaxationLabeling)'

All eight upstream tests passed, including with Ubuntu’s NumPy 1.21.5. No license has been changed.

Maestro Chess desktop app

Debian / Ubuntu · DEBFedora / RHEL family · RPMSource archive

Requires Linux, Python 3.10 or newer, xdg-utils, and a browser. Audacity is optional for editing the music.

Debian / Ubuntu

sudo apt install ./maestro-chess_0.1.1-1_all.deb

Fedora / RHEL family

sudo dnf install ./maestro-chess-0.1.1-1.noarch.rpm

Launch Maestro Chess from your applications menu, or run maestro-chess. The launcher opens a local browser app. To print its address without opening a browser, run maestro-chess --no-browser.

Closing the tab leaves the local process running. Local profiles stay on your computer and are not published to the online community. Your data lives in ~/.local/share/maestro-chess/accounts.sqlite3.
