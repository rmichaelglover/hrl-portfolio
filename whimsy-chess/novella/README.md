# The Woodland Chess Novella Editions

One game archive, several reading paths:

- `TWEEN-EDITION.md` — the complete PG story, built around the 25-game Maestro shelf.
- `CHOOSE-YOUR-OWN-ADVENTURE.md` — an optional, move-routed Master Board with ten
  opening realms and CoachZ Crossing as a branch-only chapter.
- `WOODLAND-CHRONICLES-ATTACK-OF-THE-NARNIAN-CLONES.md` — a separate companion manual
  with five smaller personal-opening realms, four study-backed bridges, and eight
  standard opening reference doors.
- `CLASSROOM-EDITION.md` — the same journey arranged as five teachable meetings.
- `ADVANCED-EDITION.md` — calculation prompts for ambitious readers.
- `APPENDIX-BALANCE-PUZZLE.md` — a quotation hunt about accuracy and balance.
- `FUTURE-AUDIENCE-PREVIEW.md` — a separate PG-capped goodbye for readers who someday outgrow the tween shelf. The main novella does not point to it.

The games themselves remain the authority. Open them in Maestro, move the pieces,
and disagree politely with the narrator.
