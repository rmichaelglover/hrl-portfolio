What this computes

Each iteration multiplies the current label support by support from compatible neighboring labels, normalizes, and applies damping. Updates are synchronous. Unsupported and isolated nodes retain their distributions. Zero-probability labels remain zero.

Inputs can come from neural models. The included example uses explicitly synthetic scores; this page does not run a neural network. Compatibility is an assumption, and increased agreement does not establish causality.

Contribution receipts

REPLAY VERIFICATION

A receipt bundles the challenge, result, and SHA-256 commitment. Verification recomputes the result and checks the commitment. This establishes reproducibility in this implementation; it is not consensus, peer review, proof of novelty, or a digital signature.

A completed run can be recorded once per challenge content on this browser.
