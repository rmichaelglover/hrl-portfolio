# Drugs Are Good

Michael Emanuel Glover, developed in dialogue with Codex. Independent conceptual and numerical medicine essay; no medical credentials are asserted. All numerical quantities are fictional and dimensionless. No clinical efficacy, safety estimate or personal treatment recommendation is supplied.

Read WHITE-PAPER.pdf, WHITE-PAPER.txt or MANUSCRIPT.md. Run `python3 experiment.py`, then `python3 write.py` in this directory. Requires Python 3, NumPy, SciPy, Matplotlib, and pdflatex with the packages listed in WHITE-PAPER.tex. SOURCE.zip includes source and results; MANIFEST.json records checksums.
